The active RRCv2 coding prompt is generated per arm by scripts/rrcv2_demo_prompt.py.
Run ./RRDdemo-local.sh a or ./RRDdemo-everos.sh a; the launcher submits the generated prompt
directly to Codex and writes the exact bound copy under runs/rrd-demo/<round>/<arm>/.

This file is intentionally not the historical four-handler audit prompt. That experiment remains
available as demo-prompt.txt but is not ReasonRenderCoding RRCv2.
